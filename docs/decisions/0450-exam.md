# 0450. Exam

Status: accepted

## Context

A quiz measures one topic at a time, and its score is the latest finished quiz. Nothing checks whether a learner still remembers what they read earlier, or tests the topics against each other. The understanding score of 0340 is also built from many small quizzes, so one question per topic is too coarse to replace it.

## Decision

An exam is a quiz whose questions come from different topics, one question per topic read.

- **Offered.** Home offers "Take an exam" once the learner has read at least ten course topics, and Progress shows the same entry. Reading a topic means it has a lesson. File topics do not count. Only one exam can be open, and starting one drops any quiz or probe in progress.
- **Length.** One question for each topic read, up to the Exam length setting of 10, 20, or 30, whose default is 10. With fewer topics read than the setting, the exam has one question per topic read. Because it is offered at ten topics, an exam is never shorter than ten.
- **Topics chosen.** When more topics are read than the length allows, the exam takes unquizzed topics first, then the lowest quiz scores, then course order. The questions are asked in course order.
- **Questions.** Each question is generated from its own topic's lesson, as a quiz question is. The next question is prefetched like a quiz's, using the plan's next topic.
- **During the exam.** It plays like a quiz: the Quiz tab is active, the title reads "Exam · Question 3 / 10 · topic", `Ctrl+N` asks the next question, `Ctrl+N` twice skips, `Ctrl+L` twice leaves, and `Ctrl+B` opens the index. Hints and clarifications are allowed. An exam cannot be extended.
- **Scoring.** The score is credit over the question count, with the weights and bands of 0340. It does not change any topic's quiz score. A finished exam's result is saved as the latest exam: its score and, for each topic asked, the credit earned.
- **Where it shows.** Progress shows the latest exam's score and band beside coverage and understanding, then each topic's result. The sidebar leads with "Exam" while one is open.
- **Review.** "Review a weak topic" on Home still names the lowest quiz score under 60%. When no quiz score is that low, it names a topic the latest exam answered incorrectly or skipped.

The session version rises to 7.

## Consequences

A learner gets a check across the course that is independent of their per-topic quizzes, so a topic they aced in a quiz can still show as forgotten. A topic's understanding figure and an exam score can disagree, which is the point. An exam makes one request per question and, for a long exam, a long session; leaving it costs the unfinished exam and keeps the previous result. This adds to the quiz rules in 0030 and 0300 and the score in 0340, and changes none of them.
